# Third-party components

PocketMic code is MIT licensed. Binary distributions also contain the following open-source components and their transitive dependencies:

- [NAudio 2.2.1](https://github.com/naudio/NAudio/tree/v2.2.1): MIT; Windows audio playback and resampling.
- [QRCoder 1.6.0](https://github.com/codebude/QRCoder): MIT; pairing QR generation.
- [.NET](https://github.com/dotnet/runtime): MIT, with third-party notices in the upstream project; bundled Windows runtime.
- [ZXing Android Embedded 4.3.0](https://github.com/journeyapps/zxing-android-embedded): Apache-2.0; QR scanner.
- [ZXing](https://github.com/zxing/zxing): Apache-2.0; QR decoding.
- [AndroidX](https://android.googlesource.com/platform/frameworks/support/): Apache-2.0; Android support libraries used by the scanner.
- [Gradle wrapper](https://github.com/gradle/gradle): Apache-2.0; build tooling.

The binary distribution license bundle in `licenses/` includes upstream license texts. The Microsoft .NET third-party notices are included in the Windows archive.

**VB-CABLE is a separate third-party product and is not included or redistributed.** The PC app downloads the original package directly from [VB-Audio](https://vb-audio.com/Cable/) when needed, with explicit vendor attribution and a donation link. VB-CABLE is Donationware; all participation is welcome. See the vendor [distribution policy](https://vb-audio.com/Services/licensing.htm). Its own licensing and terms apply.
