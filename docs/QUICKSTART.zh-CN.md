# PocketMic 快速上手

## 第一次使用

1. 下载并解压 Windows 包，运行 `PocketMic.exe`。应用以普通用户权限运行。
2. PocketMic 会自动检查虚拟麦克风，从 VB-Audio 官网下载并校验安装包后启动安装。确认管理员授权，按提示重启（如果需要）。安装完成自动识别设备，失败可点击重试。VB-CABLE 是独立 Donationware，软件内可访问官网和支持作者。
3. 在安卓手机安装 APK。此预览版本未上架应用商店。
4. 手机与电脑连接同一 Wi-Fi 或手机热点。Windows 页面选择手机可访问的网卡地址。
5. 安卓应用点击“扫码连接电脑”，核对电脑名称后保存配对；点击“连接并开启麦克风”，允许麦克风权限。
6. PocketMic 输出选择 **CABLE Input**，会议 / 游戏 / OBS 麦克风选择 **CABLE Output**。
7. 说话时观察 PocketMic 的实时波形，再用目标应用的麦克风测试确认输入。网络往返与缓冲读数不是总延迟。

## 自动更新

两端自动检查 GitHub Release 并后台获取更新。Windows 空闲时自动更新并重启应用；安卓下载完成后点击安装，由系统确认。配对和设置保留。

## 以后使用

打开电脑 PocketMic，手机点击连接。配对信息和桌面输出设置会保留。电脑 IP 地址变化、配对重置或证书变化后，重新扫码。

手机静音会停止采音并发送静音帧以保持连接；桌面“暂停输出”仅静音电脑播放，手机仍继续采音。通知栏“停止”、手机“断开”或电脑退出会结束当前连接。

## 防火墙和网络

优先使用 Windows 防火墙首次提示的专用网络授权。若没有提示或被拒绝，可将可信网络设为专用网络，然后在管理员 PowerShell 运行发行包的 `Allow-Firewall.ps1`。该脚本仅允许专用网络、本地子网的 TCP 47655，不会修改公用网络或关闭防火墙。

撤销规则：

```powershell
Remove-NetFirewallRule -Name PocketMic-Local-Audio
```

校园网 / 酒店访客网络可能隔离终端，建议手机热点。VPN 多网卡下请选择手机能访问的私有 IPv4 地址。

## USB 备选（开发者）

安装 Android Platform Tools，手机启用 USB 调试并授权自己的电脑，然后执行：

```powershell
adb reverse tcp:47655 tcp:47655
```

复制电脑的配对链接，仅把 `host=` 的值改为 `127.0.0.1`，其他字段保持原样，在安卓应用中粘贴并保存。此模式仍保留 TLS 证书绑定，不需要无线网络。拔线后需重建转发；仅向可信电脑授权 USB 调试。

## 隐私与排障

二维码和配对链接包含访问凭据，勿公开发布；若已分享，点击电脑“重新配对”撤销旧凭据。应用只在用户主动连接后采音，不保存录音。诊断导出包含连接与缓冲计数，不含音频、IP、电脑名或密钥。

部分安卓厂商需要额外允许后台运行。未安装 VB-CABLE 时可用扬声器监听验证链路；请戴耳机避免反馈。首版仍需不同真机与会议软件的兼容性验证。
